# REMONTO AI 2.1

Telegram-бот домашнего сервиса с полноценной панелью администратора.

## Что есть в панели

- главный экран с новыми, активными и просроченными заявками;
- список и поиск заявок;
- карточка заявки с клиентом, адресом, ценами и заметкой;
- изменение статуса с автоматическим уведомлением клиента;
- назначение даты и времени выезда;
- предварительная и итоговая стоимость, материалы и время работы;
- календарь на 14 дней;
- CRM-клиенты и история заказов;
- склад с минимальными остатками;
- статистика и CSV-выгрузка для Excel;
- доступ только для Telegram ID из `ADMIN_IDS`;
- журнал всех изменений заказа;
- автоматическое расширение старой SQLite-базы без удаления данных.

## Запуск

1. Установить Python 3.12.
2. Создать окружение и установить зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопировать `.env.example` в `.env` и заполнить:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   DB_PATH=data/remonto.db
   TIMEZONE=Europe/Moscow
   GOOGLE_SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/.../exec
   GOOGLE_SHEETS_WEBHOOK_SECRET=длинный_случайный_секрет
   ```

4. Запустить:

   ```bash
   python -m app.main
   ```

5. В Telegram отправить боту `/admin`.

## Обновление существующего бота

Перед заменой сборки остановить старый процесс и скопировать файл базы. У новой
версии должен быть тот же `DB_PATH`. При первом запуске недостающие поля и
индексы добавляются автоматически. Старые заявки не удаляются.

Одновременно может работать только один процесс с данным `BOT_TOKEN`.

## Railway

Проект содержит `Dockerfile`, `Procfile` и `railway.toml`. Переменные
`BOT_TOKEN`, `ADMIN_IDS`, `DB_PATH`, `TIMEZONE`,
`GOOGLE_SHEETS_WEBHOOK_URL` и `GOOGLE_SHEETS_WEBHOOK_SECRET` задаются в Variables.
Для SQLite нужен постоянный Volume; `DB_PATH` должен указывать внутрь него,
например `/data/remonto.db`.

Если обе переменные Google Sheets заданы, новая заявка и каждое изменение её
статуса, даты, стоимости или заметки автоматически отправляются в общую
таблицу. Вебхук выполняет обновление по номеру заявки, поэтому повторная
отправка не создаёт дубликаты. Ошибка Google Sheets журналируется, но не мешает
боту отвечать клиенту и администратору.

## Проверка

```bash
python -m unittest -v
```

Тесты проверяют миграцию старой базы, сохранность записей, CRUD заявок, аудит,
поиск, статистику, CSV, безопасность доступа, клавиатуры и лимиты callback_data.
