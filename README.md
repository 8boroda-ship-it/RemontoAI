# Remonto AI

Telegram-помощник домашнего сервиса **РЕМОНТО** для Брянки, Стаханова и
Алчевска.

## Что уже умеет

- принимает заявку по шагам: задача, фото, город, адрес, имя и телефон;
- распознаёт типовые бытовые работы по описанию;
- называет предварительный диапазон стоимости;
- предлагает свободные окна с учётом занятых часов и города;
- старается собирать заявки одного города в один день;
- сохраняет всё в SQLite и автоматически обновляет `data/orders.csv`;
- уведомляет мастера о новой заявке вместе с фотографиями;
- даёт мастеру команды `/orders` и `/export`.

## Быстрый запуск на Windows

1. Откройте папку проекта в VS Code.
2. В терминале выполните:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

3. Откройте `.env` и заполните:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_цифровой_Telegram_ID
```

Узнать свой числовой Telegram ID можно у бота `@userinfobot`.

4. Запустите:

```powershell
python -m app.main
```

## Настройка цен

Все услуги находятся в `config/prices.json`. Для каждой услуги можно менять:

- `keywords` — слова, по которым бот узнаёт работу;
- `price_min` и `price_max` — предварительный диапазон;
- `duration_hours` — сколько часов резервировать.

`minimum_order` задаёт минимальную стоимость выезда/заказа.

## Логика городов

Базовая сетка находится в `app/core/scheduling.py`:

- Брянка — понедельник, среда, пятница;
- Стаханов — вторник, четверг;
- Алчевск — суббота;
- воскресенье — без автоматической записи.

Это не жёсткое ограничение. Если в определённый день уже есть заявка нужного
города, алгоритм поднимает соседние свободные окна этого же дня. День с
заявками другого города получает штраф, чтобы не гонять мастера между городами.

## Таблица заявок

Рабочая база: `data/remonto.db`.

Обычная таблица для Excel: `data/orders.csv`. Она обновляется после каждой
подтверждённой заявки. Разделитель — точка с запятой, кодировка совместима с
русским Excel.

## Важно

Названная ботом цена всегда предварительная. В тексте ответа уже указано, что
материалы, сложный доступ и скрытые неисправности считаются после осмотра.
Перед реальным запуском отредактируйте `config/prices.json` под свой финальный
прайс.

## Удалённый запуск на Railway

GitHub хранит код, а Railway постоянно запускает бота на удалённом сервере.
Проект уже содержит `Dockerfile`, поэтому отдельная команда сборки не нужна.

1. Создайте в Railway новый проект из этого GitHub-репозитория.
2. В Variables добавьте:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_цифровой_Telegram_ID
TIMEZONE=Europe/Moscow
DATABASE_PATH=/data/remonto.db
ORDERS_CSV_PATH=/data/orders.csv
WORKDAY_START=09:00
WORKDAY_END=19:00
SLOT_STEP_HOURS=3
PLANNING_DAYS=21
```

3. Подключите Volume с путём монтирования `/data`. Он сохраняет базу заявок
   и CSV при обновлениях и перезапусках.
4. Дождитесь статуса `Active` и отправьте боту `/start`.

Токен нельзя добавлять в GitHub, README или Dockerfile. Он должен находиться
только в секретных переменных Railway.
